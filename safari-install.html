Safari install guide

Mac only · Roster App 1.6.19

← Back to main guide

Before you start

  • You need a Mac with Safari
  • Download the Safari package from the main guide Download tab (or button below)
  • Full Xcode is required once to convert the package into a Safari app (your IT may do this for you)

Download Safari source package

If your Mac does not have Xcode yet, ask IT to convert the source package with safari-web-extension-converter, then send you the .app. Everyday users only need the enable steps below.

1 Allow unsigned extensions (testing)

  1. Open Safari
  2. Menu bar → Develop
  3. Turn on Allow Unsigned Extensions

If you don’t see Develop: Safari → Settings → Advanced → “Show features for web developers”.

2 Enable Roster App

  1. Safari → Settings → Extensions
  2. Find Roster App
  3. Turn it ON
  4. Use Open in Safari / the toolbar button when shown

If you are the person converting with Xcode

  1. Unzip safari-roster-app-1.6.19-source.zip
  2. Run: xcrun safari-web-extension-converter /path/to/unzipped-folder
  3. Open the generated Xcode project → Run the macOS app once
  4. Then complete Steps 1–2 above in Safari
Unsigned Safari extensions are for internal testing. A signed Mac App Store / notarized build is better for wide rollout.

Troubleshooting

  • No Develop menu — enable developer features in Safari Settings → Advanced
  • Extension missing — the Safari app from Xcode must be run at least once
  • Hours won’t save — same as Chrome: wait for Google, confirm your name, try again
