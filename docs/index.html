How to install (super simple)

Follow these like a recipe. Chrome steps first — Firefox notes at the bottom.

1 Download the ZIP

Go to the Download tab and click Download for Chrome (or Firefox). The file lands in your Downloads folder.

2 Unzip the file

On a Mac: double-click the ZIP. On Windows: right-click → Extract All.

You should get a folder that contains a file named manifest.json. That folder is what you’ll load.

3 Open Extensions and turn on Developer mode

  1. Open Chrome
  2. In the address bar type chrome://extensions and press Enter
  3. Turn Developer mode ON (usually top-right)

4 Load the unpacked folder

  1. Click Load unpacked
  2. Select the unzipped folder (the one that contains manifest.json)
  3. Click Open / Select
Common mistake: Don’t select the ZIP file. Select the folder after unzipping.

5 Pin Roster App

  1. Click the puzzle-piece icon on the Chrome toolbar
  2. Find Roster App
  3. Click the pin so it stays visible
  4. Click the Roster App icon anytime to open it

Firefox install (short version)

  1. Download the Firefox ZIP or .xpi from the Download tab
  2. Open Firefox and go to about:debugging#/runtime/this-firefox
  3. Click Load Temporary Add-on…
  4. Pick manifest.json inside the unzipped folder (or the .xpi file)
Temporary Firefox add-ons disappear when you fully quit Firefox. You’ll need to load it again next time (unless your IT publishes a signed add-on later).

How to use Roster App

1) Open the app

Click the Roster App icon on your browser toolbar.

2) Choose your name

Search/select your name from the list (first time only — it remembers you).

3) Enter hours

Click into Plan / hours for the week. Add projects with:

  • Choose Client (optional)
  • Project / Task
  • The + button to add the row

Then type hours for Work Week / Sat / Sun (or weekdays, depending on your build layout).

4) Save

Click Save estimations. Wait for the success message before closing.

Caveats & easy troubleshooting

Server delay is normal. The first load of a week can take a while (sometimes ~10–30+ seconds) while Google Apps Script reads the sheet. A spinner or status line means it’s working — don’t spam-click.

If names or projects don’t load

  • Wait 20–30 seconds and open the app again
  • Check you’re online
  • On chrome://extensions, click Reload on Roster App

If Save fails

  • Confirm you selected your correct name
  • Try Save once more after a short wait
  • If you see an error code, screenshot it and send it to the DC Quality / roster owner

If Client / Project lists are empty

  • Your team needs Apps Script 1.6.19+ deployed (same web app URL)
  • Ask your admin if MetaData → Client table is up to date
  • Temporary fallback: you may still type a project name if the dropdown can’t load

Reminders

On Chrome, Roster App can remind you Mon/Tue to submit hours. Keep Chrome installed; reminders won’t fire if the extension was removed.

Still stuck?

  • Remove the extension → re-download → install again (your sheet data stays in Google Sheets)
  • Contact your roster admin with: browser name, approx time, and a screenshot of the error
