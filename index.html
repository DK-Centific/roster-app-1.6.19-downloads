How to install

Choose your browser. Steps stay on this page (Safari also has a full dedicated guide).

1 Download the ZIP

Download tab → Download for Chrome / MS Edge.

2 Unzip

Get a folder that contains manifest.json.

3 Developer mode ON

  1. Open Chrome
  2. Go to chrome://extensions
  3. Turn Developer mode ON

4 Load unpacked

  1. Click Load unpacked
  2. Select the unzipped folder (not the ZIP)
Common mistake: Select the folder after unzipping.

5 Pin Roster App

Puzzle icon → pin Roster App → click to open.

Microsoft Edge

Edge uses the same ZIP as Chrome. Steps are almost identical.

1 Download for Edge

Download tab → Download for Chrome / MS Edge (same ZIP for both).

2 Unzip

Find the folder with manifest.json.

3 Open Edge extensions

  1. Open Microsoft Edge
  2. In the address bar type edge://extensions and press Enter
  3. Turn Developer mode ON

4 Load unpacked

  1. Click Load unpacked
  2. Select the unzipped folder
If Edge asks to allow extensions from other stores, you can turn that on — for Load unpacked you mainly need Developer mode.

5 Pin & open

Extensions puzzle menu → pin Roster App.

Firefox

  1. Download the Firefox ZIP or .xpi
  2. Open about:debugging#/runtime/this-firefox
  3. Click Load Temporary Add-on…
  4. Pick manifest.json or the .xpi file
Temporary Firefox add-ons clear when you fully quit Firefox.

How to use

Illustrated steps — same style as install.

1 Open Roster App

Click the toolbar icon (pin it if needed).

2 Choose your name

Search and select your name the first time.

3 Add projects & hours

  • Optional Client
  • Project / Task
  • Press +
  • Enter hours

4 Save

Click Save estimations and wait for confirmation.

Caveats & troubleshooting

Server delay is normal. First week load can take 10–30+ seconds.

Won’t load

  • Wait and reopen
  • Check internet
  • Reload the extension

Save fails

  • Confirm your name
  • Retry once
  • Screenshot errors for admin

Empty Client / Project lists

  • Needs Apps Script 1.6.19+
  • Ask admin about MetaData Client table
