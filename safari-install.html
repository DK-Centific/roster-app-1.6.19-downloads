Before you start

  • You need a Mac with Safari
  • Download the internal .dmg below (double-click install — no Xcode)
  • This build is for Centific internal use (unsigned). Safari still needs two enable switches.

Download Roster App Safari (.dmg)

Prefer Chrome or Edge when you can — those installs are simpler. Use Safari only if your Mac workflow requires it.

1 Open the DMG and run Roster App

  1. Open Roster-App-Safari-1.6.19-internal.dmg
  2. Double-click Roster App (or drag it to Applications, then open it once)
  3. If macOS says the app can’t be opened: right-click → Open → Open
  4. Leave the small Roster window open until Safari shows the extension

2 Allow unsigned extensions

  1. Open Safari
  2. Menu bar → Develop
  3. Turn on Allow Unsigned Extensions

If you don’t see Develop: Safari → Settings → Advanced → “Show features for web developers”.

Allow Unsigned Extensions turns off when Safari fully quits. Turn it back on after a Safari restart.

3 Enable Roster App

  1. Safari → Settings → Extensions
  2. Find Roster App (or Roster App Extension)
  3. Turn it ON
  4. Use the toolbar button / Open in Safari when shown

Troubleshooting

  • No Develop menu — enable developer features in Safari Settings → Advanced
  • Extension missing — open Roster App.app from the DMG / Applications at least once, then reopen Safari
  • Gatekeeper block — right-click the app → Open (don’t just double-click the first time)
  • Hours won’t save — same as Chrome: wait for Google, confirm your name, try again

Maintainers only (rebuild)

Everyday teammates do not need this. Only if you are regenerating the Safari wrapper from the web-extension source:

  1. Unzip safari-roster-app-1.6.19-source.zip (still on the release for rebuilds)
  2. Run: xcrun safari-web-extension-converter "/path/to/safari-roster-app-1.6.19-source"
  3. In Xcode, run the macOS scheme (My Mac), then package a new .dmg
