How to install (sideload)

Manager is installed with Load unpacked — not from the Chrome Web Store. Choose your browser.

Important: If you already have the production Roster App from the Chrome Web Store, remove it or disable it before sideloading Manager, then reload carefully. Managers should use this sideload build.

1 Download the ZIP

Download tab → Download Manager 1.7.27 (Roster-Manager-1.7.27-sideload.zip).

2 Unzip

Get a folder that contains manifest.json.

3 Developer mode ON

  1. Open Chrome
  2. Go to chrome://extensions
  3. Turn Developer mode ON

4 Load unpacked

  1. Click Load unpacked
  2. Select the unzipped folder (not the ZIP)
Common mistake: Select the folder after unzipping.

5 Pin Roster Manager

Puzzle icon → pin Roster Manager → click to open.

Updating later

Sideload updates require replacing the unpacked folder contents and clicking Reload on the extension card at chrome://extensions.

How to use Manager

After install: open the extension → choose your name → click Manager view. You land on Screen B (full team). Hours come from the Onsite Hours Roster sheet (Apps Script 1.6.23+).

1 Open Roster Manager & choose your name

Click the toolbar icon (pin it if needed). Search and select your name the first time — same login flow as IC time entry.

2 Click Manager view

On the home nudge, use Manager view (alongside Plan my week). Browser / View in browser also opens Screen B full-page.

3 Screen B — full team / By Project

You land on Screen B: KPIs, people density, and By Project tiles (Active MetaData clients with logos). Click a person row to expand hours by Client · Project.

  • Current week loads first — you can interact immediately
  • Prev / next week and month warm in the background (~15 min cache)
  • KPI clicks filter; tile clicks filter project and scroll to People
  • Week / month toggles and chevrons change the period

4 Needs attention (Screen C)

From Screen B open Needs attention for Missing / Incomplete lists, Follow up, and export tools. Return with Show full team.

5 Edit clients (MetaData)

On Screen B, click Edit clients — it opens inside the extension (popup or Manager page; no new browser tab). Edit the MetaData table (client name, code, project, notes, Active/Closed). Save to sheet updates Google Sheet MetaData and refreshes By Project tiles from Active codes.

  • Stays in-app — Cancel returns to Screen B
  • Active client codes appear as By Project tiles
  • Closed stay in the catalog for IC but not on Manager tiles
  • Requires Apps Script 1.6.23+ with listMetaData / saveMetaData

6 Optional: back to time entry

Use ← Back for IC weekly estimation. Client is optional; Project/Task dropdowns apply; Admin & Training is always available. IC saves still write Onsite Collection Team (keep Roster in sync after IC edits).

Caveats & troubleshooting

Warm cache: After the first open, flipping weeks should feel fast. Soft refresh runs about every 15 minutes while the tab is visible.
Sideload updates: Replace the unpacked folder and reload the extension. Do not install Manager over the production CWS build without removing/reloading carefully.

Won’t load / blank Manager

  • Wait on first week if cache is empty
  • Check internet
  • Reload the extension on the extensions page

Edit clients fails

  • Confirm Apps Script is 1.6.23+ (New version on the same /exec)
  • Internal Client Code is required on every row

By Project all in Other

  • Set Status to Active for the client codes you want as tiles
  • Hours rows prefer the Client column when present

Save fails (time entry)

  • Confirm your name
  • Retry once after a short wait
  • Screenshot errors for admin

Empty Client / Project lists

  • Needs MetaData Client table + Apps Script 1.6.23+
  • Ask admin if lists stay empty
